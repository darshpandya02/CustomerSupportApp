Ask the Nextcloud manual

This assistant answers questions about the Nextcloud user manual (files, sharing, sync clients, two-factor authentication, Calendar, Talk and more). Every answer links to the manual sections it used. When the manual can't answer, it says so, and you can escalate to a human: a ticket is created with this conversation attached and routed to the billing, technical or account queue.

Try asking “How do I restore a deleted folder?”, “Why is my 2FA code rejected?” or “The sync client says conflicted copy, what does it mean?”
